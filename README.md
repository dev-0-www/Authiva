## Features

* Register and login
* Password management
* Login protection
* SQLite storage
* Authentication sessions
* Configurable settings
* No client mod required

## Commands

```text
/register <password> <confirmPassword>
/login <password>
/logout
/changepassword <currentPassword> <newPassword>
/unregister <password>
```

## Admin

```text
/authiva help
/authiva info
/authiva list
/authiva setpassword
/authiva unregister
/authiva delete
/authiva logout
/authiva reload
```

## Installation

Put `Authiva.jar` into your server's `plugins` folder and start the server.

## Requirements

* Paper
* Minecraft 26.2
